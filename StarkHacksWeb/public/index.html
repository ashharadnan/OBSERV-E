Quick setup and troubleshooting
  1. Bluetooth direct mode needs a browser that exposes navigator.bluetooth in a secure context.
  2. If Bluetooth is missing, use Connect with USB on desktop Chrome or Connect with bridge from any browser on the same network.
  3. For bridge mode on mobile, run the Node server on your laptop or robot computer and open this page from your phone using that machine’s local IP.
  4. Power the Arduino robot and confirm it advertises as OBSERVE-Robot or is connected over USB.
  5. Tap any button once to unlock audio before expecting spoken output.
